# 执行任务清单模板（执行层，不属于页表）

> **本文件不是页表。** 页表只负责“索引与映射”（第1~4层 + 第5层运行时正文）。
> **执行操作**（`read_block`/`edit_file`/`write_file`/`run_cmd` 验证）是独立的**任务清单**，由 leader 根据需求派发。

## 任务清单结构

每个任务一个文件，字段如下：

| 字段 | 含义 |
|:--|:--|
| **目标** | 一句话说明改什么、改完什么为真 |
| **模块** | 所属第3层模块（决定走哪条页表路径） |
| **前置** | 必须先读的页表层（通常：第2层模块导航 + 第3层部件细页表 + 第4层符号索引） |
| **步骤** | 有序执行的操作序列（调页表 → 缺页调入 → 改码 → 验证） |
| **完成标准** | 机械可检查的结论，逐条打钩 |

## 步骤写法约定

1. **先读页表，再动代码**：先按页表路径定位，用 `file_index` / `read_block` 拿到精确块，不凭记忆改。
2. **缺页调入**：只取需要的块正文，不 `read_file` 全文。
3. **精确替换**：`edit_file` 的 `old` 必须逐字符匹配，宁可先 `read_block` 确认原文。
4. **改完验证**：跑模块第3层页表里列的验证命令，exit=0 才算完成。
5. **同步页表**：若行号/签名变化，同步更新第3层和第4层页表，否则后续 `read_block` 找不到。
