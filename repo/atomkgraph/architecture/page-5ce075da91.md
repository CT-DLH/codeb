# 典型交互流程：批量导入构建、学习练习、复习提醒

三个典型交互流程，由《AtomKGraph项目计划书》拆分而来。权威源 `docs/05-交互流程.md`（26 行）。

## 流程 1：批量导入构建流程

1. 用户通过对话或 CLI 上传教材 / Markdown / PDF / Word / 飞书文档
2. AI 自动拆解为多层级原子知识点，标注来源，**默认放行**入库（可选开启「待审核队列」改为先审后入）
3. 知识点自动生成图谱节点，按**固定位置增量布局**在父节点/标签周边落位；AI 可顺带生成配套题目并入题库
4. 用户在学习过程中阅读到该知识点时**自然完成审核**：修正、拆分、标记或软删除（软删除可追溯、可恢复）
5. 图谱继承已有布局，仅新增节点落位，不触发全图重排

## 流程 2：学习练习流程

1. 用户打开知识图谱，从世界地图式全貌逐级放大，进入「运行机制 → 核心态与用户态」原子知识点
2. 侧边栏展示该知识点完整讲解（Markdown 渲染），用户可继续对话追问
3. 点击「开始练习」，系统调出该知识点关联题目
4. 答题完成后自动批改、给出解析，实时重算掌握度（结合正确率、时长、提问次数与遗忘曲线）
5. 该节点颜色同步更新，上级模块、章节进度条自动重新计算

## 流程 3：复习提醒流程

1. 遗忘曲线判定部分知识点掌握度衰减至阈值，进入复习队列
2. 系统按重要性、时效性加权，随机抽取一组高层级知识点集合发起复习提醒
3. 用户完成复习（回顾讲解 + 抽题练习），掌握度回升，更新复习队列
