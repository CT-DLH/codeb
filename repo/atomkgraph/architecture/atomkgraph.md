# AtomKGraph 是什么：本地优先的图谱化知识学习系统

一套**本地优先、对话驱动、图谱化呈现**的精细化知识学习系统。解决传统学习资料颗粒度粗、知识关联弱、掌握状态不直观、进度难量化的问题。

完整定位见 `docs/01-概述与目标.md`；技术架构见 `docs/03-技术架构.md`；当前进度见 `docs/08-实现现状.md`。

## 核心模型

- **原子知识点**是最小存储/学习单元，层级无严格深度限制，支持跨节点多对多关联。
- **不按学科隔离**：所有知识点统一存放，用**分层标签树**区分领域，目标扩展到 wiki 百科量级。
- **完全本地私有化**：知识库/题库/学习记录/向量索引全本地，LLM 与 Embedding 走在线 API。

## 闭环学习体系

「构建 → 学习 → 练习 → 评估 → 反馈 → 复习」：

1. **构建**：自然对话拆解/录入知识点；或从 Markdown/PDF/Word/飞书文档批量导入，AI 自动拆解入库（`knowledge/from-plan`）。
2. **学习**：点击节点看完整讲解与关联内容。
3. **练习**：配套习题，正确率（按难度加权）是掌握度主因子。
4. **评估**：量化掌握度，节点颜色/样式区分薄弱点与已掌握。支持**冷启动推断**——上层知识点掌握则下层视为已掌握（已会微积分则加减法视为已掌握）。
5. **复习**：掌握度按**遗忘曲线**衰减，到期抽高层知识点触发复习提醒（托盘/桌面/邮件）。
6. **进度聚合**：原子掌握度按「权重+难度」加权，自底向上汇总到模块/章节/学科。

## 图谱可视化

像**世界地图**：先呈现压缩全貌，再逐级放大下钻到原子知识点。三种视图（见 `packages/graph-engine`）——**领土**（凸包渲染掌握范围）、**地形**、**等高线**（掌握度等高）。

## 多入口

Web 对话（`apps/web` + `apps/server`）、CLI（`apps/cli`）、API、**MCP 12 工具**（`apps/mcp`，供外部 AI 助手接入）。MCP 工具面与 core 侧 chat-service 共享目录，`verify-agent-parity.mjs` 保持三方一致。

## 当前定位

以个人使用为主，架构为多人协作预留接口；后续补手机端访问。
