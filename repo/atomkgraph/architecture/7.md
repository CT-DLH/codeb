# 产品功能全景：7 个模块与未开放点

产品功能全景。权威源 `docs/02-功能模块.md`（127 行，7 模块 + 未开放点）。

## 模块 1：知识点管理与浏览（完成度 100%，已具备研发级可用性）

- 知识点增删改查（知识点前置关系、关系追溯、同义知识点聚合、知识点折叠/展开/筛选）
- 知识点主题线构建（多角色协作：AI + 人类专家；基于前置关系的拓扑排序；循环检测）
- 主题线拆分/合并（基于难度/推荐顺序 + 章节锚点，向量相似度聚合建议拆分点）
- 知识点标签系统（多标签 + 标签树；支持默认标签 {领域}；标签详情页）
- 知识点分享导出（Markdown/PDF；**export-page：选择知识点 → 勾选章节 → 生成 Markdown → 下载**）

## 模块 2：题目管理与答题（完成度 90%，可使用但无历史记录）

- 题目增删改查（填空/单选/多选/问答/编程），`relate_knowledge_ids` 多对多映射知识点
- 答题记录提交与评分（答题记录库，复习功能部分已实现）

## 模块 3：学习路径与复习（完成度 85%，基础逻辑可用）

- 基于前置关系的个性化路径生成（拓扑排序 + 难度/标签偏好）
- 每日复习队列（生成），**复习提醒机制（未开放）**
- 学习进度可视化（ProgressView：**已开放**；进度跟踪与里程碑：**已开放**）

## 模块 4：知识图谱（完成度 90%，导出/共享待开发）

- 节点与边渲染（布局算法已实现：力导向 / Sugiyama / 分层树，交互：缩放/平移/选中/高亮）
- 图谱导出（未开放：PNG/SVG/PDF/JSON 导出、**未实现**）
- 分享功能（未开放：生成共享链接，**未实现**）
- 社交交互功能（未开放：点赞、评论、收藏，**未实现**）
  - ⚠️ 其中「评论」**已部分实现**：`comment` 表 + `CommentService` + `CommentPanel` 已存在且已挂载，
    现有语义是「AI 扮演学生挑刺」（约 800 行）。真实状态与缺口见 `atomkgraph/comment-panel-and-reply-gap`。

## 模块 5：对话学习（完成度 70%，支持基础问答）

- 自然语言提问（支持上下文，记忆窗口保留最近 5 轮）
- 对话历史（标题/时间/摘要，可查看 / 撤销某轮记忆）
- 对话学习助手（正在开发，LLM 指导练习，目前支持基础问答）

## 模块 6：评估与数据分析（完成度 60%，基础指标可用）

- 掌握度评估（分多个维度；掌握度阈值可配置）
- 错题分析（未开放：错误模式统计，分析为什么会错，**未实现**）
- 学习分析（花费时间趋势/强弱项变化/知识点覆盖率，**未开放**）

## 模块 7：跨平台与多端协作（完成度 50%，Web 已上线）

- Web 端（已上线）
- 手机端适配（未开放：PWA 或 React Native，**未开放**）
- 导入导出（支持 Markdown/PDF，**部分功能可用**）

## 未开放 / 未实现点汇总

- 复习提醒机制（模块 3）
- 知识图谱导出 / 分享链接 / 社交交互（模块 4）
- 错题分析 / 学习分析（模块 6）
- 手机端适配（模块 7）

> 补充：导出方面，前端连 export API 方法都没有——见 `planning/` 下当前计划页，下一步待办就是接前端导出。
